# Security Policy

## Reporting a Security Vulnerability

SatinScroll.js is developed and maintained under the direction of **AbdulAziz Memon** (CEO of **Xantrail Studio**). We take security concerns very seriously. If you discover a vulnerability within this project, please report it privately.

* **Do not** disclose security vulnerabilities publicly until a patch or fix has been released.
* Please submit reports or security inquiries directly through official Xantrail Studio channels or contact the maintainer, **AbdulAziz Memon** (CEO of **Xantrail Studio**).

When reporting an issue, please include:
* A detailed description of the security vulnerability.
* Steps or minimal code examples to reproduce the issue.
* The potential impact on users or host applications.

Thank you for helping keep SatinScroll.js secure!
